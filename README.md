# Gupy Tracker

A ideia: tratar a busca de emprego como um problema de engenharia.

Antes de gastar esforço em uma candidatura, medir o quanto a vaga combina com o currículo, com um **Match Score** de 0 a 100%. Depois, registrar o resultado de cada candidatura e acompanhar a conversão do funil (candidatura, entrevista, oferta). Com isso dá para descobrir a partir de qual score vale a pena se candidatar.

Princípios:

- Tudo roda localmente, na máquina de quem usa.
- Dados pessoais (currículo, descrições de vagas, nomes de empresas) nunca vão para o Git.
- Metodologia aberta: os critérios e os pesos do score ficam documentados.
