# Política de segurança

## Versões suportadas

Só a branch `main` recebe correções de segurança.

## Como reportar uma falha

Se você encontrou uma falha de segurança no Gupy Tracker, **não abra uma issue pública**. Reporte de forma privada:

1. Use o recurso **Security > Report a vulnerability** (advisory privada) deste repositório no GitHub; ou
2. Se preferir, entre em contato com o mantenedor pelo perfil [@edermendes2016](https://github.com/edermendes2016).

Inclua, se possível:

- a descrição da falha e o impacto que você imagina;
- os passos para reproduzir (arquivo, comando ou endpoint envolvido);
- a versão ou o commit testado.

## O que esperar

- Confirmação do recebimento em até 7 dias.
- Avaliação inicial e retorno sobre a correção ou o prazo previsto.
- Crédito no aviso de correção, caso você deseje.

## Escopo e dados pessoais

O projeto roda na sua máquina e não envia dados a terceiros. Currículos, planilhas e dados de candidaturas ficam em pastas locais, fora do Git (ver [Proteção de dados](docs/protecao-de-dados.md)). Nunca inclua dados pessoais reais, como currículo, CPF ou tokens, no relato de uma falha.
